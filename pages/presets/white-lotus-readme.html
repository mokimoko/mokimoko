White Lotus, a preset for SillyTavern

⚙️ Setup

These are the various options you can choose from, like Length, POV, NSFW Style, etc. Choose only one of each!

🪷 Lotus Engine

This is the main prompt. It's right before the regular SillyTavern context (World Info, Character Description, and so on).

🎛️ Modules

I place the "tweaks" here so they have a decent amount of influence over the output, but not disproportionately so. You can toggle on however many of these you want. A note on the NSFW Toggle: this "activates" the NSFW prompts. The NSFW Style you chose in the Setup won't actually be inserted if this is toggled off.

🪢 Kimi Wrangling

My attempt at reining in Kimi's overthinking. It's primarily intended for Kimi 2.6 Thinking.

🛠️ Tools

These are all completely optional frills. NPC Crafter should NOT be left on or you'll get new NPCs back to back, but it's useful if you know an NPC will be appearing in the next message; it uses randomizers to create some interesting, non-stereotypical results. All the stuff after that are trackers; they REQUIRE the Tracker Rules to be toggled on. The Custom Tracker block can be used if you want to create your own tracker, but have it use my tracker rules.

🧭 Direction

The final instructions for the AI. Variety Toggle will randomize an instruction for the next turn, it's great for introducing....variety. You'd think leaving it on would be chaotic, and it CAN be, but I will say in my testing, it worked really well with GLM models and was very reasonable.

The CoTs are for Reasoning models, they're fairly straightforward. Brainstorm isn't too complex; Hyper-Mode asks the AI to consider some things that are more literature adjacent.

Q&A

Is this only for SillyTavern?

No, I also made a port for Marinara Engine, you can look at the Presets page if you missed it. I didn't test on other frontends but it's not really that complex; any frontend that supports this kind of json and the {{random}} and {{setvar}}/{{getvar}} macros might be fine.

What models does this work with?

I primarily tested with GLM 5/5.1, Kimi 2.5/2.6, and a little bit of Deepseek 3.1/3.2/4 (VERY little of that last one) and Gemma 4 31b. I prefer the Thinking variants but most of the time this worked fine with non-Thinking. The trackers in particular benefit from Reasoning capabilities.

How big is it?

I tried to keep it reasonable. It's a little bigger than Marinara's preset, much smaller than Freaky Frankenstein. However, this very much depends on what you have toggled on! The default configuration is slim, but if you have every option toggled on, it's beefier.

Does this work for group chats?

Well...I'm not sure how well it works for Group Chats actually, since I don't use those. But it won't break anything so feel free to test it out!

Sometimes the trackers don't work!

If you use less intelligent models, they're less likely to work correctly. A completely missing tracker just means the model excluded it entirely. Usually not a big deal. A broken one, where you can see the raw text, means the model either forgot the closing XML tag, or messed up the format, so the regex isn't capturing it.

What's this about an extension?

It annoys me scrolling through a ton of prompt blocks in ST's native preset drawer, so I made an extension specifically to address my annoyances! It displays the toggles you actually would realistically be controlling in an easy-to-view way, a custom side panel that opens when you click the extension's button in the ST UI (top right). It also makes it possible to run the trackers as a separate gen, for better consistency. (So your main model can focus on writing, and a sidecar can handle the stats!)

Recommendations for General Roleplay

  • Use a summary extension or whatever summary method you prefer to periodically summarize the chat; keep the context size ~30k-50k for the best coherence. (Some people are fine with a bit higher, but in my experience, this is a good setting for that.)
